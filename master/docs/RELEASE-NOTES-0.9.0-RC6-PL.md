# NetGuard 0.9.0-rc.6 — informacje o wydaniu

Wydanie porządkujące przed publikacją repozytorium. Wymaga NETGUARD-POWER `0.3.1`.

- Zmniejszono liczbę zapisów liczników odzyskiwania do NVS.
- Żądania zmieniające stan wymagają prawidłowego nagłówka same-origin.
- Poprawiono wersję i opis bezpieczeństwa TLS w panelu Home Assistant.
- Zsynchronizowano instrukcje, raporty testów oraz aktywne artefakty.
