# Lista uruchomienia produkcyjnego

Wersja: `0.9.0-rc.6`, tryb: `PRODUCTION`.

1. Zmień domyślne hasło panelu.
2. Skonfiguruj sieć i sprawdź dostęp do panelu.
3. Przypisz urządzenia do unikalnych wyjść CH1–CH4.
4. Sprawdź wszystkie cele diagnostyczne.
5. Ustaw RESET, stabilizację, ponowną próbę i limit godzinowy.
6. Sprawdź warunki i liczbę cykli każdej reguły.
7. Potwierdź UART i pojedynczy RESET każdego wyjścia.
8. Skonfiguruj konto MQTT, sprawdź Discovery, LWT oraz wszystkie komendy HA.
9. Po kontroli mapowania i dziennika włącz automatykę.
