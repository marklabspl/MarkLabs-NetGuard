# Contributing

This is a proprietary MarkLabs.pl project. Contributions require prior approval.

Before submitting a change:

1. Build both PlatformIO environments.
2. Run the Master regression checks and Power protocol tests.
3. Keep source code and code comments in English.
4. Update both Polish and English documentation for user-visible changes.
5. Never commit `.pio`, `.platformio-core`, credentials or signing keys.
6. Do not replace active release artifacts without updating version numbers,
   release notes and SHA-256 files.
